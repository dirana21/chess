# ♟️ Сетевые Шахматы Онлайн (Multiplayer Chess)

Полноценная сетевая игра в шахматы, работающая прямо в браузере без серверов и регистрации (P2P WebRTC через PeerJS) и развернутая на GitHub Pages.

---

## 🚀 Особенности игры

- 🌐 **Сетевая игра с друзьями (Online Multiplayer):** Создание приватной комнаты, отправка ссылки или 6-значного кода другу. Мгновенное подключение без задержек.
- 🤖 **Игра против компьютера (ИИ):** 3 уровня сложности (лёгкий, средний, сложный) на базе минимакса с альфа-бета отсечением.
- 👥 **Игра вдвоём на одном экране (Pass & Play):** Удобно играть на одном ноутбуке или планшете.
- ⏱️ **Контроль времени:** Пуля (1 мин), Блиц (3 мин, 5 мин), Рапид (10 мин, 15 мин) или Без времени.
- 🔊 **Встроенные звуковые эффекты:** Синтез звуков ходов, взятия фигур, шаха и победы через Web Audio API (работает офлайн без сторонних mp3).
- 🎨 **Современный интерфейс:** Темная тема в стиле Chess.com и Lichess, векторные фигуры SVG высокой четкости (Retina/4K), подсветка ходов и шаха.
- 💬 **Встроенный чат и быстрые реакции:** Эмодзи и текстовые сообщения в реальном времени.
- 👑 **Все правила шахмат:** Взятие на проходе, рокировки, превращение пешки (с модальным окном выбора фигуры), проверка шаха, мата, пата и правила 50 ходов.
- 📱 **Полная мобильная адаптивность:** Поддержка сенсорных экранов (Touch & Drag-and-drop).

---

## 🛠️ Стек технологий

- **HTML5 & CSS3** (Flexbox, CSS Grid, адаптивный дизайн)
- **Vanilla JavaScript (ES6+)**
- **[chess.js](https://github.com/jhlywa/chess.js)** — полная логика и валидация шахматных правил
- **[PeerJS](https://peerjs.com/)** — WebRTC Peer-to-Peer подключение между игроками
- **Web Audio API** — процедурный аудио-синтезатор эффектов

---

## 🌐 Как играть

1. Перейдите по ссылке на GitHub Pages.
2. Выберите контроль времени и цвет фигур.
3. Нажмите **«Создать комнату»**.
4. Скопируйте ссылку и отправьте её другу.
5. Как только друг откроет ссылку — партия начнётся автоматически!
